# BallzGame

A Unity remake of the mobile game *Ballz*: aim, launch a volley of balls and break the numbered blocks before they reach the bottom.

## Gameplay

- Click to aim and launch: all your balls are fired one after another in the same direction and bounce around the board.
- Each block shows a number and loses one point per hit; it breaks at zero.
- After each turn the rows move down one step and a new row appears, with values that grow with the turn number.
- Green blocks give you an extra ball when destroyed.
- The game ends when a block reaches the bottom row; your score is the number of turns survived.

## Tech stack

Unity 2020.3 (2D physics), C#, TextMesh Pro.

## Run it locally

1. Install Unity **2020.3.30f1**, clone the repo and open the folder with Unity Hub.
2. Open `Assets/Scenes/Accueil.unity` and press Play, then click to start.
